## 5. 규칙 검증

### 5.1 개발 카드 목록

- 승점 카드는 사용 목록에서 제외된다.
- 이번 턴에 구매한 카드는 사용 목록에서 제외된다.
- 사용 가능한 기사, 도로 건설, 풍년, 독점 카드가 목록에 포함된다.

### 5.2 기사 카드

- 기사 카드를 사용하면 카드가 제거된다.
- 기사 수가 1 증가한다.
- 도둑 이동 상태로 전환된다.
- 개발 카드 사용 플래그가 설정된다.

### 5.3 도로 건설 카드

- 카드를 사용하면 무료 도로 배치 상태로 전환된다.
- 도로 비용이 차감되지 않는다.
- 도로 말은 차감된다.
- 무료 도로 2개를 놓은 뒤 일반 상태로 돌아온다.

### 5.4 풍년 카드

- 선택한 자원 2장이 현재 플레이어에게 지급된다.
- 같은 자원 2장을 선택할 수 있다.
- 카드 사용 후 개발 카드 사용 플래그가 설정된다.

### 5.5 독점 카드

- 선택한 자원 종류를 다른 모든 플레이어에게서 가져온다.
- 다른 플레이어의 해당 자원은 0이 된다.
- 현재 플레이어는 총 획득량만큼 증가한다.

### 5.6 한 턴 1장 제한

- 하나의 개발 카드를 사용한 뒤 같은 턴에 다른 개발 카드를 사용할 수 없다.
- 턴 종료 후 제한이 초기화된다.

## 6. 회귀 테스트

- 개발 카드 구매
- 승점 계산
- 주사위 전 개발 카드 사용 가능
- 강제 처리 상태 중 개발 카드 사용 차단
- 도로 건설 카드 사용 중 턴 종료 차단

## 7. 완료 기준

- JavaScript 문법 오류가 없어야 한다.
- 코드 레벨 시나리오 테스트가 통과해야 한다.
- 로컬 서버가 응답해야 한다.
- 수행하지 못한 브라우저 테스트는 최종 보고서에 기록해야 한다.
