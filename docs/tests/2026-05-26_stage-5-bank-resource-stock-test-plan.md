## 5. 규칙 검증

### 5.1 은행 초기화

- 새 게임 또는 리셋 시 자원별 은행 재고가 19장이다.

### 5.2 자원 생산

- 생산이 일어나면 은행 재고가 지급량만큼 줄어든다.
- 한 자원 종류의 필요 지급량이 은행 재고보다 많으면 해당 자원은 아무도 받지 못한다.

### 5.3 비용 지불

- 도로, 정착지, 도시, 개발 카드 비용은 플레이어에게서 차감되고 은행으로 돌아간다.

### 5.4 은행/항구 교환

- 플레이어가 낸 자원은 은행으로 돌아간다.
- 플레이어가 받은 자원은 은행에서 차감된다.
- 은행에 받을 자원이 없으면 교환이 차단된다.

### 5.5 7 카드 버리기

- 버린 자원은 은행으로 돌아간다.

### 5.6 풍년 카드

- 선택한 자원 2장이 은행에서 차감된다.
- 은행에 없는 자원은 선택할 수 없다.
- 은행에 1장뿐인 자원은 두 번 선택할 수 없다.

## 6. 회귀 테스트

- 기존 자원 생산
- 건설
- 개발 카드 구매
- 은행/항구 교환
- 풍년 카드
- 독점 카드
- 플레이어 간 교환

## 7. 완료 기준

- JavaScript 문법 오류가 없어야 한다.
- 코드 레벨 시나리오 테스트가 통과해야 한다.
- 로컬 서버가 응답해야 한다.
- 수행하지 못한 브라우저 테스트는 최종 보고서에 기록해야 한다.
