# 구현 계획서: 3단계 개발 카드 전체 구현

작성일: 2026-05-26

## 1. 작업 목적

기본판 카탄의 개발 카드 5종을 실제로 사용할 수 있게 구현한다.

대상 카드:

- 기사
- 도로 건설
- 풍년
- 독점
- 승점

## 2. 관련 규칙

- `catan_detailed_rules.md`
- `catan_project_rule_gap_analysis.md`
- `catan_implementation_process_guideline.md`
- `docs/final_reports/2026-05-26_stage-2-turn-and-dev-limits-final-report.md`

## 3. 현재 구현 상태

2단계까지 완료된 현재 상태:

- 개발 카드는 `{ id, type, boughtTurn }` 객체로 저장된다.
- 이번 턴에 산 개발 카드는 사용할 수 없다.
- 한 턴에 개발 카드는 1장만 사용할 수 있다.
- 기사 카드만 사용 가능하다.
- 개발 카드 사용 버튼은 사실상 기사 카드 사용으로 동작한다.

## 4. 문제점

개발 카드 더미에는 도로 건설, 풍년, 독점, 승점 카드가 포함되어 있지만 기사 외 카드는 사용할 수 없다. 이 때문에 발전 카드 전략이 실제 카탄과 다르게 작동한다.

## 5. 구현 범위

- 개발 카드 사용 버튼을 공용 카드 사용 UI로 변경
- 사용 가능한 개발 카드 목록 모달 추가
- 기사 카드 사용 유지
- 도로 건설 카드 구현
- 풍년 카드 구현
- 독점 카드 구현
- 승점 카드는 사용 카드 목록에서 제외
- 도로 건설 카드 사용 중 무료 도로 2개 배치 처리
- 개발 카드 한 턴 1장 제한을 모든 사용 카드에 공통 적용

## 6. 구현하지 않을 범위

- 승점 카드 비공개 점수 UI 분리
- 은행 자원 재고 시스템
- 도로 건설 카드 사용 중 2개 미만 배치 후 취소 기능
- 개발 카드 상세 이미지 또는 카드별 그래픽
- 플레이어 간 교역
- 항구 교역

## 7. 수정 대상

- `index.html`
- `script.js`
- 필요 시 `styles.css`

## 8. 상태 변경

게임 상태에 다음 값을 추가한다.

```js
pendingFreeRoads: 0
```

도로 건설 카드 사용 시:

- 카드 1장 제거
- `usedDevThisTurn = true`
- `pendingFreeRoads = 2`
- `selectedAction = "roadBuilding"`

무료 도로 1개를 놓을 때마다 `pendingFreeRoads`를 1 감소시킨다.

## 9. 구현 순서

1. 개발 카드 버튼을 `playDev` 액션으로 변경한다.
2. 카드 이름 표시 헬퍼를 추가한다.
3. `playKnight()`를 공통 개발 카드 사용 흐름에 맞게 정리한다.
4. 개발 카드 선택 모달을 추가한다.
5. 기사 카드 사용을 모달 선택 방식으로 연결한다.
6. 도로 건설 카드 사용과 무료 도로 배치 흐름을 추가한다.
7. 풍년 카드 자원 2개 선택 모달을 추가한다.
8. 독점 카드 자원 선택 모달을 추가한다.
9. 버튼 비활성화, 턴 종료 제한, 안내 문구를 보완한다.
10. 코드 레벨 테스트를 수행한다.

## 10. 검증 방법 초안

- `node --check script.js`
- 개발 카드 목록 모달에 사용 가능한 카드만 표시되는지 확인
- 승점 카드는 사용 목록에 표시되지 않는지 확인
- 이번 턴 구매 카드는 사용 목록에서 제외되는지 확인
- 기사 카드가 도둑 이동 상태로 전환되는지 확인
- 도로 건설 카드가 무료 도로 2개를 배치하게 하는지 확인
- 풍년 카드가 선택한 자원 2장을 지급하는지 확인
- 독점 카드가 다른 플레이어의 선언 자원을 모두 가져오는지 확인
- 한 턴 1장 제한이 모든 사용 카드에 적용되는지 확인

## 11. 위험 요소

- 도로 건설 카드 사용 중 턴 종료나 다른 행동이 가능하면 상태가 꼬일 수 있다.
- 무료 도로 배치가 일반 도로 비용을 차감하면 안 된다.
- 개발 카드 모달에서 이번 턴 구매 카드가 보이면 안 된다.
- 승점 카드는 사용 카드가 아니므로 선택 목록에 표시하면 안 된다.

## 12. 롤백 방법

문제가 발생하면 `index.html`의 버튼 액션 변경과 `script.js`의 개발 카드 사용 흐름 변경을 이전 상태로 되돌린다.
