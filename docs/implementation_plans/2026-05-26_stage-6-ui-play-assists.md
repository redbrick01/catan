# 구현 계획서: 6단계 UI와 플레이 편의성 개선

작성일: 2026-05-26

## 1. 작업 목적

1~5단계에서 구현한 규칙 기능을 플레이 중 더 쉽게 확인할 수 있도록 UI를 보완한다.

중점 개선:

- 은행 자원 재고 표시
- 건설 비용표 표시
- 현재 플레이어 개발 카드 요약 표시
- 턴 단계 상태 표시
- 항구 보유 정보 표시

## 2. 관련 규칙

- `catan_detailed_rules.md`
- `catan_project_rule_gap_analysis.md`
- `catan_implementation_process_guideline.md`
- `docs/final_reports/2026-05-26_stage-5-bank-resource-stock-final-report.md`

## 3. 현재 구현 상태

현재 프로젝트는 규칙 로직이 많이 보강되었지만, 다음 정보가 화면에 명확히 드러나지 않는다.

- 은행에 남은 자원 수
- 건설 비용
- 현재 플레이어가 가진 개발 카드 종류
- 사용 가능한 개발 카드와 이번 턴 구매 카드 구분
- 현재 턴 단계
- 현재 플레이어가 소유한 항구

## 4. 구현 범위

- `index.html`에 정보 패널 추가
- `styles.css`에 작은 정보 그리드 스타일 추가
- `script.js`에 다음 렌더링 함수 추가
  - `renderTurnStage()`
  - `renderCostReference()`
  - `renderBankStock()`
  - `renderCurrentPlayerDevCards()`
  - `renderCurrentPlayerHarbors()`
- 기존 `render()` 흐름에 새 렌더링 함수 연결

## 5. 구현하지 않을 범위

- 카드 이미지 디자인
- 은행 재고 부족 애니메이션
- 개발 카드 숨김/공개 권한을 플레이어별 화면으로 완전히 분리
- 모바일 레이아웃 대규모 개편
- 실제 브라우저 수동 검증

## 6. 수정 대상

- `index.html`
- `styles.css`
- `script.js`

## 7. UI 추가 위치

오른쪽 `control-panel`에 다음 패널을 추가한다.

- 턴 상태
- 현재 플레이어 카드
- 은행 재고
- 비용표
- 보유 항구

## 8. 구현 순서

1. `index.html`에 정보 패널 컨테이너를 추가한다.
2. `styles.css`에 정보 그리드와 태그 스타일을 추가한다.
3. `script.js`에서 새 DOM 요소를 참조한다.
4. 턴 상태 렌더링 함수를 추가한다.
5. 은행 재고 렌더링 함수를 추가한다.
6. 비용표 렌더링 함수를 추가한다.
7. 현재 플레이어 개발 카드 렌더링 함수를 추가한다.
8. 현재 플레이어 항구 렌더링 함수를 추가한다.
9. `render()`에 새 렌더링 함수들을 연결한다.
10. 테스트 계획서 작성 후 검증한다.

## 9. 검증 방법 초안

- `node --check script.js`
- 새 DOM id가 모두 존재하는지 정적 검색
- 렌더링 함수가 존재하는지 정적 검색
- VM 기반 렌더링 테스트로 각 패널의 HTML이 채워지는지 확인
- 은행 재고 변경 후 패널 숫자가 반영되는지 확인
- 현재 플레이어 개발 카드 종류가 표시되는지 확인
- 보유 항구가 없을 때와 있을 때 표시가 달라지는지 확인

## 10. 위험 요소

- 기존 오른쪽 패널이 길어질 수 있다.
- 개발 카드 종류 표시가 모든 플레이어에게 보이는 구조이므로, 로컬 핫시트 플레이 전제로만 적합하다.
- 이미 한글 인코딩이 깨져 보이는 환경에서는 새 한글 텍스트도 터미널에서 깨져 보일 수 있다.

## 11. 롤백 방법

문제가 발생하면 `index.html`의 새 패널, `styles.css`의 새 스타일, `script.js`의 새 렌더링 함수와 `render()` 연결을 되돌린다.
