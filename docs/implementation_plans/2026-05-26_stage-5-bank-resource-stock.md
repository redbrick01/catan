# 구현 계획서: 5단계 은행 자원 재고 시스템

작성일: 2026-05-26

## 1. 작업 목적

현재 프로젝트는 플레이어 자원 수량만 관리한다. 카탄 기본 규칙의 자원 카드 재고와 자원 부족 규칙을 반영하기 위해 은행 자원 재고 시스템을 추가한다.

- `catan_project_rule_gap_analysis.md`
- `catan_implementation_process_guideline.md`

## 3. 현재 구현 상태

현재 자원 흐름:

- 생산 시 플레이어 자원이 바로 증가한다.
- 건설과 개발 카드 구매 시 플레이어 자원만 감소한다.
- 은행/항구 교환 시 플레이어 자원만 이동한다.
- 7 카드 버리기 시 플레이어 자원만 감소한다.
- 풍년 카드는 은행 재고 없이 자원 2장을 지급한다.

현재 문제:

- 은행 자원 카드 19장 제한이 없다.
- 자원 생산 시 은행 재고 부족 규칙이 없다.
- 비용 지불, 카드 버리기, 교환으로 자원이 은행에 돌아가지 않는다.

## 4. 구현 범위

- 은행 자원 재고 상태 추가
- 새 게임 시작 시 자원별 19장으로 초기화
- 자원 지급 함수 추가
- 자원 반환 함수 추가
- 건설 비용과 개발 카드 구매 비용을 은행으로 반환
- 초기 자원 지급 시 은행에서 차감
- 주사위 생산 시 자원 종류별 필요량을 계산하고, 부족하면 해당 자원 생산 전체 취소
- 은행/항구 교환 시 낸 자원은 은행으로 반환하고 받은 자원은 은행에서 차감
- 7 규칙으로 버린 자원은 은행으로 반환
- 풍년 카드 자원은 은행에서 지급하고, 부족하면 선택을 막음

## 5. 구현하지 않을 범위

- 은행 재고 UI 패널
- 은행 재고 부족 알림의 고급 시각화
- 개발 카드 더미 재고 UI
- 플레이어 간 교환의 은행 개입

## 6. 수정 대상

- `script.js`
- 문서 산출물

## 7. 데이터 구조 변경

게임 상태에 은행 재고를 추가한다.

```js
bank: {
  forest: 19,
  field: 19,
  pasture: 19,
  hill: 19,
  mountain: 19
}
```

## 8. 구현 순서

1. `STARTING_BANK_RESOURCES` 상수 추가
2. `game.bank` 상태 추가
3. 은행 초기화 함수 추가
4. `grantResourceFromBank()` 추가
5. `returnResourcesToBank()` 추가
6. `spend()`가 비용을 은행으로 반환하도록 수정
7. 초기 자원 지급을 은행 차감 방식으로 수정
8. 주사위 생산을 자원 종류별 일괄 지급 방식으로 수정
9. 7 카드 버리기 완료 시 은행으로 반환
10. 은행/항구 교환에 은행 재고 확인과 반환/차감 적용
11. 풍년 카드 선택 시 은행 재고 확인과 차감 적용
12. 새 게임과 리셋 시 은행 재고 초기화

## 9. 검증 방법 초안

- `node --check script.js`
- 새 게임 초기 은행 재고가 자원별 19인지 확인
- 생산 시 은행 재고가 차감되는지 확인
- 특정 자원 재고가 부족하면 해당 자원 생산이 아무에게도 지급되지 않는지 확인
- 건설 비용이 은행으로 반환되는지 확인
- 은행 교환에서 낸 자원은 은행으로 돌아가고 받은 자원은 은행에서 차감되는지 확인
- 은행 재고가 부족하면 교환이 차단되는지 확인
- 7 카드 버리기 자원이 은행으로 돌아가는지 확인
- 풍년 카드가 은행 재고 부족 자원을 선택하지 못하는지 확인

## 10. 위험 요소

- 기존 테스트와 함수 호출이 `spend()`의 부수효과 변경에 영향을 받을 수 있다.
- 생산 로직을 일괄 지급으로 바꾸면서 도시 2장 지급 계산을 정확히 유지해야 한다.
- 풍년 카드 선택 중 은행 재고가 1장뿐인 자원을 두 번 선택하는 경우를 막아야 한다.

## 11. 롤백 방법

문제가 발생하면 `script.js`의 은행 재고 상태와 자원 지급/반환 함수, 생산/교환/풍년 카드 변경을 되돌린다.
