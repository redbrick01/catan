# 온라인 모드 MVP 로드맵

## 목적

이 문서는 온라인 모드 전체 구현의 기준점이다. 목표는 공식 서비스가 아니라, 방장이 자기 PC에서 서버를 켜고 친구들이 IP 주소 URL로 접속해 함께 카탄을 플레이하는 것이다.

## 전제

중요한 것:

```text
같은 LAN 또는 소규모 온라인 방에서 접속 가능
방 만들기/참가가 쉬움
게임 상태가 모든 브라우저에서 동일함
새로고침 후 같은 플레이어로 복귀 가능
오프라인 모드는 유지
```

덜 중요한 것:

```text
공식 배포
도메인
HTTPS
회원가입
대규모 트래픽
관리자 페이지
매치메이킹
장기 통계 저장
```

## 최종 원칙

```text
서버가 정답이다.
클라이언트는 요청만 한다.
각 클라이언트는 자기에게 허용된 정보만 받는다.
친구들이 헷갈리지 않도록 UI가 현재 상태를 분명히 말해준다.
```

## MVP 범위

첫 온라인 버전에서 반드시 할 것:

```text
1. 방장이 서버를 켜고 같은 네트워크의 친구가 접속 가능
2. 온라인/오프라인 모드 선택
3. 온라인 방 만들기
4. 공유 URL 표시 및 복사
5. 친구가 URL로 방 참가
6. 대기실에서 참가자 목록 동기화
7. 방장이 게임 시작
8. 모든 브라우저가 같은 초기 게임 상태를 봄
9. 초기 배치가 서버 기준으로 동기화
10. 주사위와 턴 종료가 서버 기준으로 동기화
11. 새로고침 후 같은 플레이어로 재접속
```

MVP에서 미뤄도 되는 것:

```text
외부 인터넷 포트포워딩 완벽 지원
HTTPS
방장 이전
관전 모드
게임 저장/불러오기
오래된 방 자동 정리 고도화
공식 계정/로그인
```

## 권장 구현 순서

### MVP-A. 네트워크/방/대기실

목표:

```text
node server.js 실행
터미널에 Local/Network URL 표시
같은 와이파이의 다른 기기에서 접속 가능
```

완료 기준:

```text
방장 PC: http://127.0.0.1:4173 접속 성공
친구 기기: http://방장PC_IP:4173 접속 성공
대기실에서 참가자 목록 동기화
```

### MVP-B. 같은 보드 보기

목표:

```text
방장이 게임 시작
서버가 초기 matchState 생성
모든 브라우저가 같은 보드 렌더링
```

완료 기준:

```text
모든 브라우저의 지형, 숫자 토큰, 항구, 강도 위치가 동일
```

### MVP-C. 초기 배치 동기화

목표:

```text
초기 마을/도로 배치를 서버 명령으로 처리
모든 브라우저의 건설물이 동일하게 표시
```

완료 기준:

```text
현재 차례 플레이어만 초기 배치 가능
서버가 잘못된 초기 배치 위치를 거부
초기 배치 완료 후 play phase로 진입
```

### MVP-D. 주사위/턴 종료 동기화

목표:

```text
주사위와 턴 종료를 서버가 처리
```

완료 기준:

```text
내 차례인 브라우저만 주사위 가능
턴 종료 후 모든 브라우저의 현재 차례가 동일
```

### MVP-E. 기본 건설 동기화

목표:

```text
일반 도로/마을/도시 건설을 서버 명령으로 처리
```

완료 기준:

```text
한 브라우저의 건설 결과가 모든 브라우저에 동일하게 표시
자원 부족/잘못된 위치는 서버가 거부
```

### 이후 단계. 전체 규칙 이전

목표:

```text
교환, 개발 카드, 7/강도 순서로 서버 권위화
```

완료 기준:

```text
한 브라우저에서 한 행동이 모든 브라우저에 동일하게 반영
규칙상 불가능한 행동은 서버가 거부
```

## 현재 코드 기준 중요한 주의점

온라인 상태는 `game` 객체만으로 끝나지 않는다. 현재 코드에는 다음 상태도 함께 동기화 대상이 될 가능성이 높다.

```text
tiles
vertices
edges
harbors
robberTile
devDeck
selectedAction 일부
pendingDiscards
pendingRobberVictims
pendingFreeRoads
```

서버에서 게임 상태를 만들려면 `game`뿐 아니라 보드/말/카드/강도 위치까지 하나의 서버 상태로 묶어야 한다.

## 빠른 성공을 위한 기준

첫 성공 목표는 "카탄 전체 온라인 완성"이 아니다.

첫 성공 목표:

```text
친구가 URL로 들어온다.
대기실에 이름이 뜬다.
방장이 시작한다.
모두 같은 보드를 본다.
초기 마을/도로 배치가 모두에게 반영된다.
그 다음 주사위와 턴 종료가 모두에게 반영된다.
```

이 지점까지 작게 성공한 뒤 일반 건설, 교환, 개발 카드, 강도를 순서대로 붙인다.
