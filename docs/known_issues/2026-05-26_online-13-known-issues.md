# 온라인 13단계 Known Issues

작성일: 2026-05-26

## 판정 요약

13단계 자동 회귀와 코드 감사 기준으로 즉시 수정 가능한 P0/P1은 남기지 않았다. 다만 실제 Chrome 3기기 LAN 플레이와 일부 브라우저 입력 기반 모달 검증은 현재 실행 환경에서 수행하지 못했으므로, 최종 실기기 사용 가능 판정은 보류한다.

## P0

없음.

## P1

없음.

13단계 중 P1 후보로 확인한 항목은 다음과 같이 처리했다.

- `lastRobberResult.id`가 새로고침 후 같은 결과 모달을 반복 표시할 수 있는 문제: `sessionStorage` 기반 표시 이력으로 보강.
- 은행 재고가 부족한 동일 자원 생산에서 여러 플레이어가 영향을 받을 때 일부 플레이어만 자원을 받는 문제: 공식 규칙에 맞게 해당 자원 생산을 모두 지급하지 않도록 서버 생산 로직 수정.

## 현재 사용 가능성 판단

- 자동 테스트/코드 감사 기준: P0/P1 없음.
- 로컬 브라우저 smoke 기준: 기본 화면 로드, 보드 렌더, 콘솔 오류 없음.
