# 구현 계획

이 폴더는 구현 전에 작성한 계획서를 보관한다. 기능별 현재 상태 요약은 `docs/features/`를 먼저 보고, 세부 작업 이력은 이 폴더의 날짜별 계획서를 본다.

## 파일명

```text
YYYY-MM-DD_<area>-<sequence>-<short-title>-plan.md
YYYY-MM-DD_<area>-<short-title>-plan.md
```

## 주요 묶음

- `stage-*`, `play-*`: 오프라인 규칙과 플레이성 보강
- `online-*`: WebSocket 온라인 모드
- `bot-*`: 봇 플레이어와 봇 러너
- `game-feel-*`, `ui-*`: 시각 피드백, 사운드, UI/UX 개선

## 작성 기준

새 계획서는 [문서 작성/배치 규칙](../guides/documentation-style-guide.md)의 계획서 형식을 따른다.
