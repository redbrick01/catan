# 최종 보고서

이 폴더는 완료된 작업의 최종 보고서와 gate summary를 보관한다.

## 파일명

```text
YYYY-MM-DD_<area>-<sequence>-<short-title>-final-report.md
YYYY-MM-DD_<area>-<short-title>-summary.md
```

## 작성 기준

최종 보고서는 구현이 실제로 무엇을 바꿨는지, 어떤 검증을 통과했는지, 어떤 위험이 남았는지를 짧고 명확하게 남긴다. 형식은 [문서 작성/배치 규칙](../guides/documentation-style-guide.md)을 따른다.
