## 1. 작업 개요

4단계 작업으로 기존 은행 4:1 교환만 지원하던 교역 시스템을 확장했다. 항구 데이터, 항구 교환 비율, 플레이어 간 단일 자원 교환을 추가했다.

## 3. 구현 내용

### 3.1 플레이어 교환 버튼 추가

`index.html`에 `data-action="playerTrade"` 버튼을 추가했다.

현재 턴 플레이어가 상대 플레이어 1명을 선택하고, 서로 자원 1장씩 교환할 수 있다.

### 3.2 은행 교환 비율 표시 추가

은행 교환 UI의 고정 `4장 →` 표시를 `tradeRatioLabel`로 바꿨다.

현재 플레이어가 소유한 항구와 선택한 자원에 따라 다음처럼 표시된다.

- 기본: `4장 →`
- 일반 항구: `3장 →`
- 특정 자원 항구: `2장 →`

### 3.3 항구 데이터 생성

`setupHarbors()`를 추가했다.

보드 생성 후 외곽 교차점에 항구 9개를 배정한다.

항구 구성:

- 일반 3:1 항구 4개
- 목재 2:1 항구 1개
- 밀 2:1 항구 1개
- 양 2:1 항구 1개
- 벽돌 2:1 항구 1개
- 철 2:1 항구 1개

### 3.4 항구 렌더링

`drawHarbors()`를 추가했다.

항구는 외곽 교차점 바깥쪽에 작은 토큰과 텍스트로 표시된다.

### 3.5 항구 소유 판정

다음 함수를 추가했다.

- `playerHarbors(playerId)`
- `tradeRatioFor(playerId, resourceType)`

현재 단순화된 판정:

- 항구가 붙은 교차점에 정착지나 도시를 가진 플레이어가 항구를 소유한다.

### 3.6 은행/항구 교환 확장

`bankTrade()`가 더 이상 항상 4:1을 쓰지 않는다.

적용 순서:

1. 특정 자원 2:1 항구를 소유하고 선택 자원이 해당 자원이면 2:1
2. 일반 3:1 항구를 소유하면 3:1
3. 그 외에는 4:1

### 3.7 플레이어 간 교환

`showPlayerTradeModal()`을 추가했다.

동작:

- 현재 턴 플레이어만 교환을 시작한다.
- 상대 플레이어를 선택한다.
- 내가 줄 자원 1장과 상대에게 받을 자원 1장을 선택한다.
- 양쪽이 해당 자원을 보유하고 있을 때만 교환한다.

## 4. 규칙 반영 내용

이번 작업은 다음 규칙을 반영했다.

- 자기 턴 플레이어가 다른 플레이어와 교역할 수 있다.
- 자기 턴이 아닌 플레이어끼리는 교역하지 않는다.
- 기본 은행 교환은 4:1이다.
- 일반 항구는 3:1 교환을 제공한다.
- 특정 자원 항구는 해당 자원 2:1 교환을 제공한다.
- 항구 효과는 해당 항구 위치에 정착지나 도시가 있을 때만 적용된다.

## 6. 남은 이슈

- 플레이어 간 교역은 단일 자원 1:1 교환만 지원한다.
- 상대의 명시적 수락/거절 단계는 없다.
- 항구는 실제 Catan처럼 바다 변 양끝에 붙는 방식이 아니라, 외곽 교차점 1개에 붙는 단순화된 방식이다.
- 은행 자원 재고 시스템이 없으므로 교환 시 은행 재고 부족은 고려하지 않는다.
