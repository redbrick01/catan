# 최종 보고서: PLAY-006 보드 숫자 토큰 공식 배치 적용

작성일: 2026-05-26  
관련 문제 문서: `docs/issues/2026-05-26_playability-issues.md`  
관련 계획서: `docs/plans/2026-05-26_play-006-board-randomizer-balance.md`

## 1. 작업 목적

숫자 토큰을 완전 랜덤으로 섞던 기존 방식을 Catan 공식 가변 보드 숫자 토큰 배치 방식으로 바꾼다.

## 2. 확인한 공식 규칙

Catan 25주년 영문 공식 규칙서의 `Set-Up, Variable` 항목을 기준으로 했다.

확인한 규칙:

- 숫자 토큰 18개를 문자 면이 보이도록 정렬한다.
- 섬의 한 모서리에서 시작한다.
- 지형 타일에 숫자 토큰을 알파벳 순서로 놓는다.
- 바깥쪽에서 중심으로 반시계 방향 나선형으로 진행한다.
- 사막은 건너뛰며, 사막에는 숫자 토큰을 놓지 않는다.
- 완전 랜덤 숫자 배치를 선택하는 경우에는 빨간 숫자끼리 인접하지 않게 교환한다.

참고:

- `https://www.catan.com/sites/default/files/2021-07/catan-25th-rules_eng-200313.pdf`

## 4. 수정 내용

숫자 토큰 배열을 상수로 분리했다.

```js
const NUMBER_TOKENS = [5, 2, 6, 3, 8, 10, 9, 12, 11, 4, 8, 10, 9, 4, 5, 6, 3, 11];
```

이 배열은 A~R 문자 순서의 기본판 숫자 토큰 순서를 의미한다.

기존 동작:

- 지형 타일을 섞는다.
- 숫자 토큰 배열도 섞는다.
- 비사막 타일에 무작위 숫자를 배정한다.

변경 후 동작:

- 지형 타일은 계속 섞는다.
- 숫자 토큰은 섞지 않는다.
- 보드 좌표를 바깥 고리에서 안쪽으로 정렬한다.
- 선택한 시작 모서리에서 반시계 방향 나선 순서로 타일을 정렬한다.
- 사막은 건너뛰고 A~R 순서 숫자를 배치한다.

추가한 함수:

- `axialDistance(coord)`: 보드 중심으로부터 몇 번째 고리인지 계산
- `spiralAngle(tile)`: 보드 중심 기준 각도 계산
- `officialNumberTokenOrder()`: 공식 나선형 숫자 배치 순서 계산
- `assignOfficialNumberTokens()`: 사막을 건너뛰며 A~R 숫자 토큰 배정

테스트 편의를 위해 `getStateSummary()`에 타일의 `id`, `q`, `r`, `type`, `number`를 포함했다.

## 5. 검증 결과

통과:

- `node --check script.js`
- 기존 숫자 토큰 셔플 제거 확인
- `NUMBER_TOKENS` 상수와 공식 배치 함수 확인
- 브라우저에서 `http://127.0.0.1:4173/?test=1` 로드 확인
- 보드에 숫자 토큰 18개 렌더링 확인
- 사막 타일 1개 렌더링 확인

수행하지 못한 검증:

- `getStateSummary()`로 타일 좌표와 숫자 배정 순서를 직접 읽어 A~R 순서와 대조하는 검증

이유:

- 인앱 브라우저 평가 환경에서 `window.__catanTest` 접근이 되지 않아 테스트 헬퍼 기반 상태 검증을 수행하지 못했다.

## 6. 남은 위험

- 시작 모서리는 프로젝트 보드 좌표 기준의 상단 왼쪽 모서리로 고정했다. 공식 규칙은 "한 모서리"에서 시작하므로 임의 선택이 가능하다.
- 현재 보드 지형은 계속 무작위 배치다. 숫자 토큰만 공식 A~R 나선형 배치로 바뀌었다.
- 완전 랜덤 숫자 배치 시 적용하는 빨간 숫자 인접 방지 스왑 규칙은 이번 구현 대상이 아니다.

## 7. 최종 판단

완료

PLAY-006의 수정 방향을 단순 6/8 인접 방지가 아니라 공식 숫자 토큰 배치 방식으로 조정했고, 숫자 토큰 셔플을 제거해 A~R 나선형 배치를 구현했다.
