## 5. 규칙 검증

### 5.1 항구 생성

- 보드 생성 후 항구 9개가 생성된다.
- 항구 종류에 3:1 일반 항구와 특정 자원 2:1 항구가 포함된다.

### 5.2 항구 교환

- 항구가 없으면 기본 4:1 교환이 적용된다.
- 일반 항구를 소유하면 3:1 교환이 적용된다.
- 특정 자원 항구를 소유하면 해당 자원은 2:1 교환이 적용된다.
- 특정 자원 항구는 다른 자원에는 2:1을 적용하지 않는다.

### 5.3 플레이어 간 교환

- 현재 턴 플레이어와 선택한 상대가 자원 1장씩 교환한다.
- 현재 턴 플레이어가 줄 자원이 없으면 교환되지 않는다.
- 상대가 줄 자원이 없으면 교환되지 않는다.
- 자기 턴이 아닌 플레이어끼리는 교환되지 않는다.

### 5.4 교역 타이밍

- 주사위 전에는 은행 교환과 플레이어 교환이 차단된다.
- 강제 처리 상태 중에는 교역이 차단된다.
