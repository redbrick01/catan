- 콘솔 오류 여부 확인

## 6. 규칙 검증

### 6.1 7 카드 버리기

검증 항목:

- 8장 이상 보유 플레이어가 있으면 자동 폐기하지 않고 모달이 표시된다.
- 버릴 수량이 `Math.floor(보유 카드 / 2)`로 계산된다.
- 선택 수량이 부족하거나 초과하면 완료할 수 없다.
- 완료 후 실제 자원이 차감된다.
- 모든 대상자가 완료한 뒤 도둑 이동 단계로 넘어간다.

### 6.2 도둑 약탈 대상 선택

검증 항목:

- 약탈 가능한 상대가 없으면 바로 건설/교환 단계로 돌아간다.
- 약탈 가능한 상대가 1명이면 자동으로 무작위 자원 1장을 가져온다.
- 약탈 가능한 상대가 여러 명이면 선택 모달이 표시된다.
- 선택한 상대에게서만 자원 1장을 가져온다.

### 6.3 도로 연결 규칙

검증 항목:

- 상대 건물이 있는 교차점은 내 도로 연결점으로 인정되지 않는다.
- 내 건물 또는 빈 교차점은 내 도로 연결점으로 인정된다.

### 6.4 최장 교역로

검증 항목:

- 상대 건물이 내 도로 중간에 있으면 길이 계산이 그 지점에서 끊긴다.
- 동률이면 기존 보유자가 유지된다.
- 기존 보유자가 없고 동률이면 보너스가 부여되지 않는다.

## 7. 회귀 테스트

## 8. 완료 기준

- JavaScript 문법 오류가 없어야 한다.
- 메인 화면과 게임 보드가 정상 렌더링되어야 한다.
- 1단계 규칙 변경에 대한 코드 레벨 검증이 통과해야 한다.
- 수행하지 못한 테스트는 최종 보고서에 명시해야 한다.
