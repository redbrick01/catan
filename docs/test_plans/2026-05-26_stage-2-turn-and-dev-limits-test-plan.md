# 테스트 및 검증 계획서: 2단계 턴과 개발 카드 제한 정교화

작성일: 2026-05-26  
관련 구현 계획서: `docs/implementation_plans/2026-05-26_stage-2-turn-and-dev-limits.md`

## 1. 테스트 대상

- 주사위 전 건설, 교환, 개발 카드 구매 제한
- 주사위 후 건설, 교환, 개발 카드 구매 허용
- 개발 카드 객체 구조
- 새로 산 개발 카드 사용 제한
- 한 턴에 개발 카드 1장 사용 제한
- 기사 카드 사용 후 최대 기사력 처리 유지
- 승점 카드 계산 유지

## 2. 변경 파일

- `script.js`

## 3. 테스트 환경

- Node.js 정적 문법 검사
- `script.js` VM 로드 기반 코드 레벨 시나리오 테스트
- 로컬 서버 응답 확인

## 4. 정적 테스트

- `node --check script.js`
- `newDev` 참조 제거 확인
- `boughtTurn`, `usedDevThisTurn`, `canTakePostRollAction()` 존재 확인

## 5. 규칙 검증

### 5.1 행동 타이밍

검증 항목:

- 주사위 전에는 도로, 정착지, 도시, 개발 카드 구매, 은행 교환이 차단된다.
- 주사위 후에는 비용과 위치 조건을 만족하면 행동할 수 있다.
- 카드 버리기, 도둑 이동, 약탈 대상 선택 중에는 후속 행동이 차단된다.

### 5.2 개발 카드 구매

검증 항목:

- 개발 카드 구매 시 문자열이 아니라 객체가 저장된다.
- 카드 객체에는 `id`, `type`, `boughtTurn`이 들어간다.
- 구매한 개발 카드 수는 UI 표시용 `player.dev.length`로 유지된다.

### 5.3 개발 카드 사용 제한

검증 항목:

- 이번 턴에 산 기사 카드는 사용할 수 없다.
- 이전 턴에 산 기사 카드는 사용할 수 있다.
- 한 턴에 기사 카드를 2장 사용할 수 없다.
- 턴 종료 후 `usedDevThisTurn`이 초기화된다.

### 5.4 점수 계산

검증 항목:

- 승점 카드 객체가 `visiblePoints()`에 반영된다.
- 기사 카드 사용 후 최대 기사력 계산이 유지된다.

## 6. 회귀 테스트

- 게임 시작 상태 초기화
- 개발 카드 더미 생성
- 주사위 굴림
- 건설 비용 차감
- 은행 교환
- 턴 종료
- 승리 판정

## 7. 완료 기준

- JavaScript 문법 오류가 없어야 한다.
- 코드 레벨 시나리오 테스트가 통과해야 한다.
- 수행하지 못한 브라우저 테스트는 최종 보고서에 기록해야 한다.
