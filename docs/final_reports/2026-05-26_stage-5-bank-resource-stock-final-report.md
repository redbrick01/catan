5단계 작업으로 은행 자원 재고 시스템을 추가했다. 이제 자원 생산, 비용 지불, 은행/항구 교환, 7 카드 버리기, 풍년 카드가 은행 재고와 연결된다.

## 3. 구현 내용

### 3.1 은행 재고 상태 추가

자원별 시작 재고를 19장으로 정의했다.

```js
const STARTING_BANK_RESOURCES = {
  forest: 19,
  field: 19,
  pasture: 19,
  hill: 19,
  mountain: 19
};
```

`game.bank`에 현재 은행 재고를 저장한다.

### 3.2 은행 지급/반환 함수 추가

추가한 함수:

- `resetBank()`
- `grantResourceFromBank(player, type, amount)`
- `returnResourcesToBank(resources)`

`spend()`도 수정해 건설과 개발 카드 구매 비용이 은행으로 돌아가도록 했다.

### 3.3 초기 자원 지급 수정

두 번째 초기 정착지에서 받는 시작 자원도 은행에서 차감되도록 수정했다.

### 3.4 주사위 생산 수정

`produce()`를 일괄 지급 방식으로 변경했다.

반영된 규칙:

- 같은 자원 종류의 총 필요 지급량을 먼저 계산한다.
- 은행 재고가 충분하면 모두 지급한다.
- 은행 재고가 부족하면 해당 자원은 아무도 받지 못한다.
- 일부 플레이어에게만 지급하지 않는다.

### 3.5 비용 지불 반환

다음 비용은 은행으로 반환된다.

- 도로 건설
- 정착지 건설
- 도시 업그레이드
- 개발 카드 구매

### 3.6 은행/항구 교환 수정

`bankTrade()`를 은행 재고 기반으로 수정했다.

동작:

- 플레이어가 낸 자원은 은행으로 돌아간다.
- 플레이어가 받는 자원은 은행에서 차감된다.
- 은행에 받을 자원이 없으면 교환이 차단된다.

### 3.7 7 카드 버리기 반환

7 규칙으로 버린 자원이 은행으로 돌아가도록 수정했다.

### 3.8 풍년 카드 수정

풍년 카드가 은행 재고를 확인하도록 수정했다.

동작:

- 선택한 자원은 은행에서 차감된다.
- 은행에 없는 자원은 선택할 수 없다.
- 은행에 1장뿐인 자원은 같은 자원을 두 번 선택할 수 없다.
- 유효한 자원 2장을 선택해야 카드가 실제로 사용된다.

## 4. 규칙 반영 내용

이번 작업은 다음 규칙을 반영했다.

- 자원 카드는 은행 재고 한도 안에서 지급된다.
- 생산에 필요한 자원이 부족하면 해당 자원은 아무도 받지 못한다.
- 일부 플레이어에게만 나누어 주지 않는다.
- 건설, 개발 카드 구매, 교환, 카드 버리기로 자원이 은행에 돌아간다.
- 풍년 카드는 은행에서 자원 2장을 가져온다.

## 5. 테스트 결과

### 5.1 통과

- `node --check script.js`
  - JavaScript 문법 오류 없음
- 정적 검색
  - `STARTING_BANK_RESOURCES` 확인
  - `game.bank` 확인
  - `resetBank()` 확인
  - `grantResourceFromBank()` 확인
  - `returnResourcesToBank()` 확인
- 로컬 서버 HTTP 확인
  - `http://127.0.0.1:4173/` 응답 코드 200 확인
- 코드 레벨 시나리오 테스트
  - 은행 재고 자원별 19장 초기화
  - 생산 시 은행 재고 차감
  - 은행 재고 부족 시 해당 자원 생산 전체 취소
  - 도로 건설 비용 은행 반환
  - 은행 교환 시 낸 자원 반환과 받은 자원 차감
  - 은행 재고 부족 시 교환 차단
  - 7 카드 버리기 자원 은행 반환
  - 풍년 카드 자원 은행 차감
  - 은행에 1장뿐인 자원은 풍년 카드로 두 번 선택 불가

### 5.2 수행하지 못한 테스트

- 실제 브라우저 UI 클릭 테스트

이유:

- 이전 단계에서 인앱 브라우저가 로컬 URL 접근을 `net::ERR_BLOCKED_BY_CLIENT`로 차단했다.
- 이번 단계도 VM 기반 코드 레벨 테스트와 로컬 서버 HTTP 응답 확인으로 대체했다.

## 6. 남은 이슈

- 은행 재고를 화면에 보여주는 UI는 아직 없다.
- 은행 재고 부족 상황을 더 눈에 띄게 표시하는 UX는 아직 없다.
- 플레이어 간 교역은 은행을 거치지 않으므로 은행 재고와 무관하게 동작한다.
- 독점 카드는 플레이어 간 자원 이동이므로 은행 재고와 무관하게 유지했다.
