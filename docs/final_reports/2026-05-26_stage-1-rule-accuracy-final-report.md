## 3. 구현 내용

### 3.1 선택 모달 추가

`index.html`에 공용 모달 영역을 추가했다.

이 모달은 다음 상황에서 사용된다.

- 7 규칙으로 버릴 자원 선택
- 도둑 약탈 대상 선택

`styles.css`에는 모달, 카드 버리기 행, 약탈 대상 버튼 스타일을 추가했다.

### 3.2 도로 연결 규칙 보완

`script.js`에 `canConnectThroughVertex()`를 추가했다.

이제 상대 정착지나 도시가 있는 교차점은 내 도로 연결점으로 인정하지 않는다.

반영된 규칙:

- 내 건물은 연결점으로 사용 가능
- 빈 교차점은 연결점으로 사용 가능
- 상대 건물은 연결점으로 사용 불가

### 3.3 최장 교역로 계산 보완

`longestRoadLength()`에서 DFS 탐색 중 상대 건물이 있는 교차점에 도착하면 그 지점 너머로 진행하지 않도록 수정했다.

`updateLongestRoad()`도 보완했다.

반영된 내용:

- 길이 5 이상만 최장 교역로 후보
- 기존 보유자가 동률이면 유지
- 기존 보유자가 없고 동률이면 보너스 없음
- 후보가 없으면 최장 교역로 보유자 제거

정착지 건설 후에도 최장 교역로를 다시 계산하도록 했다.

### 3.4 7 카드 버리기 선택 UI 추가

기존 `discardForSeven()` 자동 폐기 방식을 제거하고 `startDiscardForSeven()`와 `showDiscardModal()`을 추가했다.

반영된 규칙:

- 자원 카드 8장 이상 보유자만 대상
- 버릴 수량은 보유량의 절반 내림
- 플레이어가 직접 버릴 자원을 선택
- 선택 수량이 정확히 맞아야 완료 가능
- 모든 대상자가 완료한 뒤 도둑 이동 단계로 전환

### 3.5 도둑 약탈 대상 선택 UI 추가

`moveRobber()`를 수정하고 `showRobberVictimModal()`을 추가했다.

반영된 규칙:

- 약탈 가능한 상대가 없으면 약탈 없이 진행
- 약탈 가능한 상대가 1명이면 즉시 무작위 자원 1장 약탈
- 약탈 가능한 상대가 여러 명이면 현재 플레이어가 대상을 선택
- 선택한 상대에게서만 자원 1장을 무작위로 가져옴

### 3.6 턴 상태 보호

`discard`, `robber`, `robberVictim` 상태에서는 턴 종료와 다른 행동 버튼을 비활성화했다.

## 4. 규칙 반영 내용

이번 작업은 다음 규칙을 반영했다.

- 상대 건물은 내 도로망 연결을 차단한다.
- 상대 건물은 최장 교역로 계산에서도 도로를 끊는다.
- 7이 나오면 8장 이상 보유자는 버릴 자원을 직접 선택한다.
- 도둑 약탈 대상이 여러 명이면 현재 플레이어가 대상을 선택한다.

## 5. 테스트 결과

### 5.1 통과

- `node --check script.js`
  - JavaScript 문법 오류 없음
- 로컬 서버 HTTP 확인
  - `http://127.0.0.1:4173/` 응답 코드 200 확인
- 코드 레벨 시나리오 테스트
  - 상대 건물 교차점으로 도로 연결 불가
  - 빈 교차점으로 도로 연결 가능
  - 상대 건물이 최장 교역로를 차단
  - 9장 보유 시 4장 버리기 대상 생성
  - 버리기 완료 후 도둑 이동 단계 전환
  - 약탈 대상이 여러 명이면 대상 선택 단계 진입

### 5.2 수행하지 못한 테스트

- 인앱 브라우저 화면 렌더링 테스트

이유:

- 인앱 브라우저가 `http://127.0.0.1:4173/`와 `http://localhost:4173/` 접근을 `net::ERR_BLOCKED_BY_CLIENT`로 차단했다.

대체 검증:

- 서버 응답 200 확인
- JavaScript 문법 검사
- 실제 `script.js`를 VM에 로드한 코드 레벨 규칙 시나리오 테스트 수행
