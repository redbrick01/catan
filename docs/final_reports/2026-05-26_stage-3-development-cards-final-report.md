# 최종 보고서: 3단계 개발 카드 전체 구현

작성일: 2026-05-26

## 1. 작업 개요

3단계 작업으로 기본판 카탄의 개발 카드 사용 기능을 확장했다. 기존에는 기사 카드만 사용할 수 있었으나, 이제 도로 건설, 풍년, 독점 카드도 사용할 수 있다.

## 3. 구현 내용

### 3.1 개발 카드 사용 버튼 공용화

`index.html`의 기존 기사 버튼을 공용 개발 카드 사용 버튼으로 변경했다.

변경 전:

```html
<button type="button" data-action="knight">기사</button>
```

변경 후:

```html
<button type="button" data-action="playDev">카드 사용</button>
```

### 3.2 개발 카드 선택 모달 추가

`showDevCardModal()`을 추가했다.

동작:

- 현재 플레이어의 사용 가능한 개발 카드를 표시한다.
- 승점 카드는 표시하지 않는다.
- 이번 턴에 구매한 카드는 표시하지 않는다.
- 한 턴에 이미 개발 카드를 사용했다면 사용을 차단한다.

### 3.3 기사 카드 유지

기존 기사 카드 사용 흐름을 새 개발 카드 공통 구조에 맞게 정리했다.

동작:

- 기사 카드 제거
- 기사 수 증가
- 개발 카드 사용 플래그 설정
- 도둑 이동 상태로 전환
- 최대 기사력 갱신

### 3.4 도로 건설 카드 구현

`playRoadBuilding()`을 추가했다.

동작:

- 도로 건설 카드 제거
- 개발 카드 사용 플래그 설정
- 무료 도로 배치 상태 진입
- 최대 2개의 도로를 자원 비용 없이 배치
- 도로 말은 정상 차감
- 무료 도로 배치가 끝나면 일반 도로 선택 상태로 복귀

보호 처리:

- 남은 도로 말이 없으면 사용 불가
- 무료 도로를 놓을 수 있는 위치가 없으면 사용 불가
- 무료 도로 배치 중에는 다른 행동과 턴 종료를 차단

### 3.5 풍년 카드 구현

`showYearPlentyModal()`을 추가했다.

동작:

- 원하는 자원 2장을 선택
- 같은 자원을 두 번 선택 가능
- 선택 완료 후 자원 지급
- 카드 제거 및 개발 카드 사용 플래그 설정

### 3.6 독점 카드 구현

`showMonopolyModal()`을 추가했다.

동작:

- 자원 종류 하나 선택
- 다른 모든 플레이어의 해당 자원을 전부 현재 플레이어에게 이동
- 획득량을 로그에 기록
- 카드 제거 및 개발 카드 사용 플래그 설정

### 3.7 승점 카드 처리

승점 카드는 사용 카드 목록에 표시하지 않도록 했다.

현재 승점 카드 점수 계산은 2단계의 객체 기반 `visiblePoints()` 로직을 유지한다.

## 4. 규칙 반영 내용

이번 작업은 다음 규칙을 반영했다.

- 기사 카드는 도둑을 이동시키고 기사 수를 증가시킨다.
- 도로 건설 카드는 도로 2개를 무료로 놓는다.
- 풍년 카드는 원하는 자원 2장을 가져온다.
- 독점 카드는 선언한 자원을 다른 플레이어에게서 모두 가져온다.
- 승점 카드는 일반 사용 카드가 아니다.
- 개발 카드는 한 턴에 1장만 사용할 수 있다.
- 이번 턴에 구매한 개발 카드는 사용할 수 없다.

## 5. 테스트 결과

### 5.1 통과

- `node --check script.js`
  - JavaScript 문법 오류 없음
- 정적 검색
  - `playDev` 버튼 확인
  - `showDevCardModal()` 확인
  - `playRoadBuilding()` 확인
  - `showYearPlentyModal()` 확인
  - `showMonopolyModal()` 확인
  - 기존 `data-action="knight"` 제거 확인
- 로컬 서버 HTTP 확인
  - `http://127.0.0.1:4173/` 응답 코드 200 확인
- 코드 레벨 시나리오 테스트
  - 사용 가능한 개발 카드만 목록에 포함
  - 승점 카드와 이번 턴 구매 카드 제외
  - 기사 카드 사용 후 기사 수 증가와 도둑 이동 상태 전환
  - 같은 턴 두 번째 개발 카드 사용 차단
  - 도로 건설 카드 사용 후 무료 도로 2개 배치
  - 무료 도로 배치 시 자원 비용 미차감
  - 풍년 카드로 같은 자원 2장 획득
  - 독점 카드로 다른 플레이어의 선택 자원 전부 획득

### 5.2 수행하지 못한 테스트

- 실제 브라우저 UI 클릭 테스트

이유:

- 이전 단계에서 인앱 브라우저가 로컬 URL 접근을 `net::ERR_BLOCKED_BY_CLIENT`로 차단했다.
- 이번 단계도 VM 기반 코드 레벨 테스트와 로컬 서버 HTTP 응답 확인으로 대체했다.

## 6. 남은 이슈

- 승점 카드 비공개 점수 처리는 아직 구현되지 않았다.
- 은행 자원 재고 시스템이 없으므로 풍년 카드는 은행 재고 부족을 고려하지 않는다.
- 도로 건설 카드 사용 중 취소 기능은 없다.
- 실제 브라우저에서 모달 UI와 클릭 흐름은 한 번 더 확인하는 것이 좋다.
